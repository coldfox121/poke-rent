# 宝可梦房东（poke-rent）

宝可梦题材的类《幸运房东》游戏。扮演被火箭队逼债的训练家，靠一台改装精灵球机赚钱交保护费。

## 玩法

- 5 列 × 4 行 = 20 格老虎机，每转消耗 1 金币
- **开局固定御三家 3 只**（妙蛙种子 / 小火龙 / 杰尼龟），对齐原作且不让开局过易
- 转完从 3 只宝可梦里选 1 只加入卡池，也可跳过
- 每格产出 = 基础值；每有 1 个被自己克制的邻居，独立结算一次 `基础值 ×2`，多次相加（完整规则见右上角「规则」页）
- 累计上屏 4 次触发进化，一阶变二阶（基础 1 → 3），对应格子闪光 + 「进化！」标记
- **7 轮交租通关，每轮固定 5 转**（一局约 35 转），租金 58 → 1728，前松后紧；进度显示当前所在轮次，开局 1/7、交租一次 2/7
- 转动演出：20 格同时变问号 → 同时亮出结果 → **停留 0.5 秒** → 行优先逐格结算，贡献的宝可梦跳动一下 + `+N` 浮标标注克制来源（如「克草 ×3」），金币逐格飞入顶部；空格不占演出时间，可随时点「跳过动画」
- 三选一/道具弹窗在**顶部统一显示档位概率**（普通 68.5% / 非凡 30% / 稀有 1.5%），卡片只标稀有度；弹窗可点「收起」**飞向右下角悬浮按钮**（带动画），对照上轮结果再决定，点按钮飞回展开
- 三选一选中的宝可梦若转盘有空位则立即填入一个空位；满格时保持现状，下一转随机抽取
- **上屏规则（原作逻辑）**：卡池里每种宝可梦每转各上屏一次、随机铺位；卡池 3 只 → 上屏 3 只 + 17 空格；卡池超过 20 才随机抽 20 只。卡池里的重复个体也重复上屏，卡池 chip 显示每种张数 ×N
- **交租奖励**：每次交租后固定发放 2 张精灵中心券（删牌）+ 1 个精灵球（刷新），并给一次**道具 3 选 1**
- 道具 3 选 1 与宝可梦共用「先抽稀有度档、再抽具体项」的加权逻辑；但不套用「交租后强制非凡」这条宝可梦专用规则
- 顶栏「图鉴」按钮（精灵球图标）：18 只宝可梦，**首次选入卡池点亮**（开局御三家也算），跨局保留；展示 PokeAPI 简体中文官方图鉴说明 + 基础信息（属性 / 基础收益 / 进化条件 / 稀有度）。点击转盘或卡池里的宝可梦可直接跳到对应图鉴条目
- 顶栏「规则」按钮（📜 图标）：集中展示目标、转动、基础产出、属性克制奖励、进化、稀有度、道具、图鉴等规则与 6 属性克制表；属性克制奖励规则不再写进图鉴
- **首次进入新手引导**：分步高亮转动 / 格子 / 卡池 / 交租 / 图鉴，跨局只显示一次，可从规则页「重看新手引导」再次打开
- 侧边栏「贡献金币排名」记录本局每只宝可梦的产出，默认折叠，重开清零
- **管理员调试窗口**：连点顶栏「进度」5 次并输入密码打开 3×3 格子，可拖动或点选任意宝可梦入格，只结算中心格（周围 8 格仅作克制来源、不结算自身），用于验证克制结算规则

## 属性克制（首版 6 属性）

| 属性 | 克制 |
|---|---|
| 火 | 草、冰 |
| 水 | 火、地面 |
| 草 | 水、地面 |
| 电 | 水 |
| 地面 | 电、火 |
| 冰 | 草、地面 |

相邻判定：8 邻域（上下左右 + 四斜角），不含首尾环绕。结算顺序：行优先（第一行左到右，逐行到第四行）。

## 稀有度（三选一抽取）

稀有度按 Poke'Catch 的 tierOf 规则（捕获率 / 进化阶段 / 种族值）划分，产出数值暂不受稀有度影响：

| 档位 | 宝可梦 | 1.0x 权重 |
|---|---|---:|
| 普通 | 走路草、六尾、可达鸭、小磁怪、地鼠、小海狮、雪童子（7 只） | 68.5% |
| 非凡 | 皮卡丘、三地鼠、白海狮（3 只） | 30% |
| 稀有 | 妙蛙种子/草、小火龙/火恐龙、杰尼龟/卡咪龟、雷丘、大岩蛇（8 只） | 1.5% |

- 原作 1.0x 是 68/30/1.5/0.5，本作无「非常稀有」档，0.5% 并入普通。
- 第 1 次交租前只抽普通；交租 1 次后解锁非凡，2 次后解锁稀有。
- 交租后的首次三选一强制非凡以上（刷新保留该属性）。
- 坂木的契约、神奇糖果每层让非普通档权重 ×1.2，可叠加（对齐原作 Lucky Carrot 类道具效果）。
- 道具 reward 沿用同一套稀有度分档：普通（提神咖啡/回收/传送带/学习装置）、非凡（坂木的契约/破碎的精灵球/幸运蛋）、稀有（神奇糖果）。

## 内容分类

- **上屏符号**（占格子、参与联动）：18 只宝可梦 = 6 属性 × (2 只进化链 + 1 只单体)
- **永久物品**（当局生效、不可关闭，共 8 件）：提神咖啡、坂木的契约、破碎的精灵球、回收、传送带、学习装置（每转 +1）、神奇糖果（稀有度 ×1.2）、幸运蛋（进化阈值 -1，最低 2）
  - 咖啡与破碎的精灵球不可叠加；其余可叠加
- **消耗品**（一次性）：精灵球（刷新 3 选 1）、精灵中心券（移除卡池 1 个符号）；有券时卡池 chip 上出现独立的 × 按钮用于删牌，点 chip 主体则是进图鉴

## 运行

直接双击 `index.html` 即可游玩。存档在浏览器 localStorage 中。

## 素材来源

- 宝可梦精灵图：PokeAPI sprites（已下载到 `assets/pokemon/`，运行时不联网）
- 道具图标：pokedex.wiki CDN（已下载到 `assets/items/`）
- UI 框/背景：CSS 自制

## 测试

```bash
node tools/simulate.mjs      # 规则单测 + 策略平衡模拟
node tools/migrate-test.mjs  # 存档纯加法迁移测试
node tools/e2e.mjs           # 浏览器端到端（含演出与排名）
node tools/live-check.mjs https://poke-rent.pages.dev  # 线上验收
```

当前平衡（每种策略 200 局）：**开局御三家 3 只后贪心约 1% / 随机 0% / 跳过 0% 通关率**。按用户要求，**租金曲线暂不随开局卡池缩小而调整**，等宝可梦特殊能力初版落地后一并重新扫描平衡（避免频繁改租金）。此前 6 只开局版本为贪心 64.5% / 随机 24.5% / 跳过 0%。

演出时序参数（毫秒）集中在 `js/data.js` 的 `ANIM`，后续接调速 UI 只需覆盖它。

## 后续需求（已登记，尚未实现）

1. **宝可梦特殊效果**：目前收益只有基础值、属性克制、进化提升，同属性宝可梦区分度不足。后续给部分宝可梦加被动/触发效果。
2. **流派权重抽取**：有特殊效果后，三选一概率从「纯稀有度权重」升级为「稀有度 + 流派权重」，让构筑有方向。
3. **新稀有度判定规则**：现有分档沿用 Poke'Catch 算法。后续改为按**基础收益 + 属性数量（双属性克制收益更高）+ 特殊能力**多重判断，需要单独定规则。
