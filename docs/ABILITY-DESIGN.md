## 四、效果类型速查（写想法时可参考）

| kind | 含义 | 参数 |
|---|---|---|
| flat | 自身固定加金 | value |
| counterFlat | 每克制 1 个邻居额外加 | value, max |
| positionFlat | 按位置加（角落 / 边缘 / 内部 / 底行） | corner, edge, inner, bottomRow |
| nearbyCountFlat | 邻域每有 1 只宝可梦加 | value, max |
| nearbyTypeFlat | 相邻每有 1 只指定属性加 | type, value, max |
| neighborFlat | 给相邻格加（可限属性 / 仅左右） | value, targetType, scope, max |
| typeCountFlat | 场上某属性数量达标加 | type, n, value |
| noCounterFlat | 自己没克制任何邻居时加 | value |
| selfZero | 自身产出归零 | — |
| counterTargetFlat | 被自己克制的邻居格加 | value |
| suppress | 被克制邻居本转不产出（二期） | value |
| untouchable | 不参与克制关系（二期） | value |

标签（tag）：`burst` 爆发 / `board` 铺场 / `control` 控制 / `econ` 经济 / `position` 位置 / `aura` 光环 / `environment` 环境 / `tradeoff` 代价。

强度分：0~3，后续用于稀有度重算；草案里 4 表示明显超模、需要重点复核。

## 五、结算顺序（固定，避免先后争议）

1. 预计算每格「被谁克制 / 克制了谁」
2. 控制标记：先全场标记被压制的格子，再结算
3. 光环汇总：同名光环取最高，不叠加、不链式触发
4. 逐格结算（行优先）：基础值 → 克制次数 × 基础值 × 2 → 能力加算 → 光环 → 单格上限
5. 整转收尾：处理「本转结束」类条件
6. 道具加成：回收 / 学习装置最后加
7. 输出每格明细与 links（复用现有跳动、飘字、金币飞入演出）

硬规则：

- 能力加成不参与克制倍率
- 控制类最低收益为 0，不出现负数
- 单个能力每转上限 +6
- 全盘能力总增益上限 = 当前轮租金 × 50%

## 六、平衡守则

| 项目 | 建议 | 说明 |
|---|---|---|
| 普通档能力 | 每转 ≤ +3 | 简单、通用、好理解 |
| 非凡档能力 | 每转 ≤ +4 | 可以带条件或光环 |
| 稀有档能力 | 每转 ≤ +6 | 可以改规则，但要有上限 |
| 光环叠加 | 同名取最高 | 防止多只六尾互相叠加 |
| 回归门槛 | 随机 20%~40%，跳过 0%，贪心 70%~85% | 特殊能力上线后重扫租金曲线 |
